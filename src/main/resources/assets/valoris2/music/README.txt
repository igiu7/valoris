Put your .mp3 files in this folder (src/main/resources/assets/valoris2/music/) and rebuild the mod.
In game one of them, chosen at random, plays all the time as the game music (Music volume slider),
and the vanilla music is replaced. Sub folders work too. File names: lowercase letters, digits, _ - . only
(Minecraft resource rules), e.g. battle_of_grunwald.mp3
A resource pack can add more tracks in assets/valoris2/music/ as well.
